# DeepSeek Harness Threads 0.14.0

本版本调整线程结果同步逻辑，并修复持久化、发送重试与消息展示问题。

## 线程结果同步

- 原「同时发到主对话」改为「在主会话展示线程结果」，默认关闭。
- 线程 Agent 独立执行；主会话在原回答下展示结果卡片，不新增主 Agent 任务。
- 卡片按请求 ID 更新，展示处理中、完成、失败等状态及助手正文，并提供线程入口。
- 共享记录随线程索引持久化，重新加载后恢复。
- 「带回主对话」继续写入输入草稿，用户编辑后可明确发送。

## 缺陷修复

- Host 串行写入，客户端按变更键保存，保留其他页面的数据。
- 启动恢复保留期间新增的线程、草稿及删除操作，已挂载输入框即时同步恢复内容。
- 保存失败显示提示，支持自动退避和手动重试。
- 发送失败重试保留原始文字、图片及请求 ID，避免误发历史消息。
- 回复统计排除父会话历史，后台完成保留未读状态，长线程按需加载历史。
- 切换面板校验子会话绑定，避免线程统计交叉写入。
- Slack 模式保留可折叠推理正文，以及插话中的图片和文件。

## 安装

Web 版：

```powershell
dsh plugin --profile web add github:LeoAndJellyfish/DeepSeek-Harness-Threads#v0.14.0
```

桌面端使用当前宿主的插件管理器安装相同 GitHub 版本。支持 desktop profile 管理的桌面自带 CLI 也可安装已下载的 `dsh-threads-0.14.0.tgz`。

早期 `@local/dsh-threads` 安装需迁移到 `dsh-threads`，保留 `$DSH_HOME/dsh-threads/store.json`。Host 与客户端应同时更新，安装后重启宿主并刷新界面。
