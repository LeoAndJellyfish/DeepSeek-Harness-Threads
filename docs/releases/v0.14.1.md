# DeepSeek Harness Threads 0.14.1

修复桌面安装验收中发现的线程恢复问题，保留 0.14.0 的被动结果卡片和全部缺陷修复。

- 线程使用 `dsh-resource://dsh-threads/<parent>/<seq>` 资源地址保存锚点，宿主重启后可恢复。
- 旧版无有效锚点的页签显示线程列表，选择后继续讨论。
- 首次 Host 迁移合并未同步的浏览器线程、文字草稿；成功保存后标记完成，后续恢复保留 Host 删除结果。
- 线程独立执行，主会话展示结果卡片；“带回主对话”写入草稿。

安装固定版本：

```powershell
dsh plugin --profile web add github:LeoAndJellyfish/DeepSeek-Harness-Threads#v0.14.1
```

桌面端使用宿主插件管理器或支持 desktop profile 的桌面自带 CLI 安装。安装后正常重启宿主。

资源包含 TGZ、ZIP 和 SHA256SUMS，发布后逐项下载校验。
