# dsh-threads Bug Fixes Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复审查确认的数据保存、异步恢复、发送重试、线程统计和 Slack 消息展示缺陷。

**Architecture:** 保留现有 Host 路由和客户端插槽结构。Host 串行提交完整快照；客户端保留初始化期间的本地操作，按顺序提交保存，并为失败消息保存独立重试内容。线程统计仅处理锚点之后的事件，已读状态仅随面板阅读推进。Slack 展示保留推理和附件。

**Tech Stack:** JavaScript ESM、Node.js 内置 node:test / node:vm、现有 DSH 插件 API。

---

### Task 1: Host 保存
- 修改 `index.js`：串行写入、独立临时文件、异常清理；通过 Cordis 服务注入绑定路由。
- 新增 `test/host-store.test.js`：并发 PUT、失败恢复、请求校验与延迟服务绑定。
- 先验证旧实现的失败用例，再验证修复。

### Task 2: 客户端持久化与草稿
- 修改 `client.js` 的存储模块：初始化期间按键合并本地操作；同步 localStorage 与草稿订阅；串行保存并检查 HTTP 状态、保留失败待保存状态。
- 新增 `test/client-store.test.js`：延迟 GET、删除草稿、已挂载草稿恢复、保存失败及串行写入。

### Task 3: 发送与回复状态
- 修改 `client.js` 的 ThreadPanel / ThreadRepliesLine：失败请求保留原始文字及图片；主会话拒绝显示错误并单独重试；正确统计锚点之后的用户消息、完成时间和未读。
- 新增 `test/thread-behavior.test.js`：发送失败重试、图片、主会话拒绝、历史前缀计数和未读。

### Task 4: Slack 内容展示
- 修改 `client.js` 的 SlackAssistantNode / SlackSteeringNode：提供可展开的推理正文；插话保留图片和文件。
- 新增 `test/slack-rendering.test.js`：推理、纯图片插话、文字及附件。

### Task 5: 集成验证
- 添加 Node 测试辅助模块、`npm test` 和 CI 测试步骤。
- 更新 CHANGELOG / README 的修复与验证信息，保持当前版本号，暂不发布。
- 执行 `npm test`、`npm run check`、`npm pack --dry-run` 并检查 diff。
- 验收标准：已确认缺陷均有行为回归测试，所有检查通过；源文件以外不访问实际 DSH 状态。
